# Project VLVM Stage4: 实验安排和结果

## 微调结果汇总

### Phase B 评测口径

- 四档都从同一个 `tsp3d_scanrefer.pth` 初始化，训练 3 epoch，seed=0；训练集为 123 个场景、23031 个 view、89620 条 query record，验证集为 14 个场景、2638 个 view。
- 分层学习率固定为 G1=`1e-4`、G2=`5e-5`、G3=`1e-5`，weight decay=`1e-4`，gradient clip=`0.1`；Presence gate 和新增 ranking/hard-negative 均关闭。
- 全量 E3 使用 14 个 val 场景、2638 个视图、2590 个正查询和 2638 个负查询；`sigma_tar=0`，每个视图最多取一个负查询，所有已跑权重均为 5228 次调用、`failures=0`。
- `U0e3/U2e3` 在最终 epoch 初筛后未进入 epoch 复评；Pareto 候选 `U1/U3` 补齐了 epoch1–3。
- 区分度统计把“正查询且 Top-1 IoU≥0.25”定义为正确预测；正查询 miss 与负查询预测都定义为错误。因不同权重的 Top-1 框不同，这组 AUROC/AUPRC 同时反映定位与置信度排序，不是固定候选集上的纯分类指标。
- `gap` = 正确预测分数均值 − 全部错误预测分数均值；`pair acc` = 同一视图中正确正查询分数高于 target-absent 负查询分数的比例（tie 计 0.5）。
- ECE/Brier/NLL 直接使用未做 temperature scaling 的原始置信度，并以 IoU≥0.25 正确性为标签。

### Phase B 结论与 checkpoint 选择

1. **U0 淘汰。** 只训练 `cls_conv` 同时损失定位和分数间隔，说明问题不是单纯 bias/temperature 校正。
2. **U2/U3 不进入主线。** 加入 layer4/3 没有超过 U1 的总体定位与 AUPRC，继续解冻 vision backbone 的收益为负；U2 的 potted plant 和 U3 的负查询压分只作为诊断现象保留。
3. **U1e1/e2 不可选。** U1e1 的纯排序接近 scanrefer，但总体定位下降，potted plant/toilet 崩塌；U1e2 总体 IoU 最高，却有 potted plant 1.79% 和更差的 AUROC/FPR。
4. **Phase C 的 R0 参照与解冻边界锁定为 U1e3。** 权重为 `data/tsp3d_ft/unfreeze/u1_5080_ckpt_epoch3.pth`；其模型参数与 `u1_5080_ckpt_last.pth` 完全一致。它在定位（hit@0.50 12.43%、mean IoU 0.1716）、类别恢复和同视图排序（0.8886）之间最均衡。
5. **区分度问题尚未解决。** U1e3 相对 base 仅小幅提高 AUROC（0.8041 vs 0.7993）和 pair accuracy（0.8886 vs 0.8650），但 AUPRC 更低（0.4107 vs 0.4377），FPR@TPR95 更高（0.7854 vs 0.7227）；相对 scanrefer 的高召回拒识仍明显较弱。因此下一步必须直接优化候选排序，而不是继续扩大解冻层数。

### R1v1 结果分析：分数形状与区分度

**三个判断与结论**

- R1v1 三个 epoch 未完全收敛：限定于排序项与 box 项，val `L1`/`GIoU` 三轮单调下降，`rank` 非单调（0.9416→0.9780→0.9285）；E3 侧最强指标全部落在 E3（hit@0.25 33.63%、AUROC 0.8363、AUPRC 0.4511），未见平台；`cls_base` 反而 E1 最低
- 分数区间收窄、区分度变好：区间收窄，hit 概率 sd 0.2181→0.1342、logit sd 1.0693→0.5937；区分度变好，AUROC 0.8046→0.8363、AUPRC 0.4112→0.4511、pair acc 0.8910→0.9127；绝对均值差变小：0.2323→0.2061（logit 1.1111→0.9486）；标准化差距变大：Cohen's d 1.1931→1.4356（logit 1.1510→1.3881）
- 仍有负目标分数高于正目标，但比之前少：每视图“最硬错误分数 > 最高正样本分数”的违例率 10.90%→8.73%；pair acc 与 AUROC 同向改善；残余落差中位 0.0736→0.0726（几乎未变）

##### 结果分析 / 判断

- 增加 epoch 和引入 Gate 会使得部分分数形态和排序指标改善，但通常同时造成 hit@0.25、hit@0.50 和 mean IoU 等定位指标下降（*主要改变分数分布和拒识行为，同时带来少量定位损失*）。分数治理与排序改善没有转化为定位收益，不能仅依据 AUROC、gap、FPR 或校准指标选择权重。

- Gate 机制在联合训练和独立训练中的*净作用稳定存在*，但*增益很小*，并伴随少量正确目标被关闭。独立 Gate-only 训练相对联合训练略有优势，但差距有限，仍不足以替换 R1v1 E3；该权重现已定名为 VLVM V1 并作为 S4 最终权重。

### P1 penalty

新 P1 不再沿用 legacy `t_S + floor + radius` 三参数口径。P0 的 S 分布、P1-legacy 离线重放和三档 radius 导航结果共同支持将机制收缩为一个在线搜索参数：

| 新 P1 penalty 项 | 固定选择 | 证据 |
| :--- | :--- | :--- |
| covered 权重 | $w_S=\min\left(1,\max(S,0.1)/t_S\right)$ | 保留 S 随数值连续衰减的作用，同时让低端异常值最多衰减到由 `s_min/t_S` 派生的下界 |
| uncovered 权重 | $w_S=1$ | P0 中 uncovered precision 为 64.54%，与全部候选 64.33% 基本一致；没有证据支持把“无覆盖”直接视作负证据 |
| `s_min` | 代码内固定 `0.1`，不暴露参数 | `0.1` 约位于 covered S 的 p5；仅 131/3755（3.49%）个 covered 候选低于它，且该低端子集 precision 仅 49.62% |
| S query radius | 代码内固定 `0.5 m`，不暴露参数 | 与 P0 计算口径一致；legacy P1-B 的 `0.3/0.5/0.7 m` 三档导航极差仅 SR 0.34 pp、Oracle 0.34 pp、SPL 0.0011、SoftSPL 0.0007 |
| 独立 `floor` | 删除 | P1-A 表明多个 floor 在部分区域结果完全相同；高 floor 又会把 $w_S$ 推近 1，使 penalty 退化。新公式只保留由 $0.1/t_S$ 自然产生的最低权重 |
| 唯一搜索参数 | `t_S` | 固定项均有分布或在线导航证据，下一轮无需把算力继续分散到 floor/radius |
